Pacote PWA / Web App - Gíria Games

Inclui:
- icons/: versões PNG transparentes para PWA, favicon e Android.
- icons-maskable/: versões com zona segura para ícones maskable.
- icons-ios-glass/: versões com efeito glass para iOS.
- apple-touch-icon.png: ícone iOS normal.
- apple-touch-icon-glass.png: ícone iOS com efeito glass.
- manifest.webmanifest: manifesto PWA.
- sw.js: service worker simples para cache/offline.
- pwa-head.html: código pronto para colar no <head>.
- logo-original-transparente.png: logo original preservado.

Nota: para usar o estilo glass no iPhone/iPad, mantém no <head>:
<link rel="apple-touch-icon" href="./apple-touch-icon.png?v=2">

Todos os PNG foram exportados com fundo transparente.

Regras Globais do Sistema

Estas regras controlam quando o sistema tenta enviar notificações. O envio só acontece para utilizadores com push ativo neste dispositivo.

Enviar notificação antes da abertura
Escolhe quantas horas antes da abertura queres avisar.
Enviar quando o mercado abrir
Dispara o aviso no momento da abertura da janela.
Enviar quando o mercado fechar
Dispara o aviso no momento do fecho da janela.
Jogos para Prognóstico disponíveis
Envia um aviso semanal quando os jogos já estiverem prontos para palpitar.
Jogos para Prognóstico fecharam
Envia um aviso semanal quando a fase de prognósticos fechar.
Jogos para Prognóstico vão fechar
Envia um aviso semanal algumas horas antes do fecho dos prognósticos.

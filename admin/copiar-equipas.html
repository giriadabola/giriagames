Copiar & Sincronizar Equipas (FootyStats)

Passo 1: Exportar Equipas do Firebase
Clica no botão para ler todas as equipas do teu Firebase e copiar a lista para a Área de Transferência. Depois cola o texto aqui no chat.
Passo 2: Importar e Atualizar Embeds no Firebase
Clica no botão roxo para carregar os dados das 424 equipas processadas automaticamente (ou cola o JSON manualmente) e depois clica em "Atualizar Equipas no Firebase".
